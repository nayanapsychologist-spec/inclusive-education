Topic: Class 3 IEP Progress Monitoring Data Collection & Re-evaluations (India Framework)

Module Context: Class 3 IEP Data Collection

In Class 3 (Grade 3), students undergo a critical developmental shift from learning to read to reading to learn, alongside acquiring multi-digit arithmetic operations. For students with disabilities, systematic progress monitoring ensures timely intervention adjustments.

Key Objectives

  • Learn to administer free diagnostic tests aligned with ASER (Pratham) and NCERT / NIPUN Bharat benchmarks.
  • Collect reliable quantitative data across key domains (Reading Fluency, Comprehension, Mathematics, Behavior).
  • Utilize data to make informed re-evaluation decisions under the RPWD Act 2016 framework.

Data Collection Methods Summary

Method When to Use Class 3 Example
Frequency / Event Recording Discrete behaviors with clear start & end. Counting unprompted sight words read correctly.
Duration Recording Measuring length of time a behavior lasts. Time student stays focused on an independent writing task.
Latency Recording Measuring time from prompt to initiation. Time taken to open text book after instruction.
Permanent Product Reviewing completed work samples. Scoring math worksheets or handwriting sheets using a rubric.

Re-evaluation & Triennial Review Framework (RPWD Act 2016 Guidelines)

Re-evaluations must be conducted at least once every 3 years, or when significant changes in student performance occur.

Key Re-evaluation Decision Flow

  1. Review Existing Data: Analyze weekly progress monitoring trends, work samples, and teacher logs.
  2. Identify Needed Additional Data: Determine if standardized testing (e.g., SLD diagnosis review) or multi-disciplinary assessments (OT, SLP) are required.
  3. Determine Eligibility & Services: Does the student continue to meet criteria under RPWD Act categories? Are accommodations/modifications sufficient?
  4. Update IEP Goals: Revise SMART goals based on baseline data collected during re-evaluation.

Checklist for Re-evaluation Readiness

  • Minimum 8–12 data points collected per IEP goal.
  • Multi-tiered intervention logs reviewed.
  • General Education teacher feedback documented.
  • Parent input and observation form completed.
